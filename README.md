# Neha Soni — Personal Portfolio

A conversion-focused personal portfolio for **Neha Soni**, a web designer and developer based in India and working with clients worldwide. The site presents services, process, testimonials, selected projects, and clear paths for prospective clients to get in touch.

## Highlights

- Responsive, editorial-style single-page portfolio
- Selected-work gallery with interactive case-study modals
- Project links for Jonathan Otafia, Eula Mae's, Aroma & Brew, Ongoing, BookBlaze, and Northbound
- Service overview for website design and development, landing pages, e-commerce, and website audits
- Mobile navigation, scroll-reveal animations, custom cursor, and accessible modal controls
- Social, email, and booking links

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans and DM Serif Display)
